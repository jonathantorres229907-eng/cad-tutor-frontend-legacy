# CAD Tutor Frontend (Legacy)

Collection of early and experimental frontend builds created during initial development of the CAD Tutor platform.

## Contents 
- Early React/Vite prototypes
- Deprecated UI layouts
- Initial component experiments
- Unfinished or broken builds

## Purpose 
This repository documents the evolution of the CAD Tutor frontend. It preserves early design attempts, helping track progress and architectural decisions over time.
